Discover → Connect → Do

Find something you’d enjoy together.

Try the TasteSocial journey in about five minutes. No account, quiz or backend setup required.

Use a new private browser window for this walkthrough. Your choices save to that browser. This guide does not reset or replace an existing Passport. Film examples are real catalog references, not live listings. The friend and plan responses are explicitly simulated. No messages, bookings or real agreements are made.
Start with your interests

  1. Pick a couple of tastes

    In Passport, set Animation and Fantasy to Like, then select Save interests. Sharing can stay off. No assessment needed.

    Open Passport

  2. Discover a specific idea

    Select Find specific things. Open Spring, read the explanation and source information, and save it. The demo uses short films; Charlotte cafés and activities are the next catalog priority.

    Explore Spring · See your saved ideas

  3. See what you have in common

    Open Together and select Use sample friend. Check the shared interests and why each film could suit both of you. Suggest Spring to create a local proposal draft.

    Open Together

  4. Turn an idea into a plan

    Expand Explore demo decision steps. Express interest for yourself and simulate the friend’s interest. Enter invented date/place details, propose them, and approve as each simulated participant. The state becomes scheduled.

    Change the details to see both approvals reset. This plan is an in-page simulation: reloading clears it. Separate-account invitations and persistent plans require the connected test environment.
