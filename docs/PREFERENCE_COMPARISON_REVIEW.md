# Truthful legacy comparisons

The same-phone Escape pair result and cross-device challenge result displayed a clamped, uncalibrated 43–98% travel match. The remote ring even painted a fixed 82% regardless of answers. These claims did not meet the Bible's evidence standard.

Both flows now compare supplied quiz dimensions directly: the number within 10 points on the explicit 0–100 answer scales, closest preference, largest difference and the existing compromise ideas. The count's denominator is the number of supplied dimensions, not people or real-world outcomes. It is symmetric and is neither a compatibility probability nor a validated predictor. The playful travel-theme label remains; compatibility assertions, percentage rings and booking language are removed. The share story carries the same limitation.

`comparison-core.js` contains validation and raw difference calculations. `app.js` and `challenge.js` reuse it without changing quiz scoring, Passport history, link encoding or challenge receipt. Unit tests exercise endpoints, symmetry and invalid values; the browser regression completes both same-phone and separate-context challenge journeys, checks raw counts against encoded results, and protects mobile layout.

No new data storage, external calls, services or account requirements. Existing score snapshots and links remain compatible. Actual shared-item recommendations continue to use Together's separate fair catalog ranker.

Validation: all 28 Node suites, dependency-free syntax check, production build, nine browser suites at both URL bases, focused final-CSS root comparison check and both intercepted configured Plans builds passed. Screenshots: `screenshots/preference-comparison/`. No SQL changed; existing local authorization/privacy/recovery gates were rerun at the beginning of this audit and passed. Physical-device and hosted account checks remain unverified.
